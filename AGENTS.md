## Code Style Guidelines

### Python Style
- **Formatting:**
  - Indentation: **4 spaces**.
  - Line Length: limit to ~80-100 characters.
  - Imports: Sorted alphabetically. `import os`, `import sys`, etc.
- **Naming Conventions:**
  - Files: `snake_case.py`
  - Variables/Functions: `snake_case` (e.g., `sanitize_slug`, `get_pending_insights`)
  - Constants: `UPPER_CASE` (e.g., `INSIGHTS_DIR`)
  - Classes: `PascalCase`
- **Docstrings:**
  - Provide concise docstrings for all functions, explaining the purpose, arguments, and return values.
  - Example:
    ```python
    def sanitize_slug(slug):
        """Sanitizes the slug to snake_case."""
        ...
    ```

### Script Structure
- **Shebang:** Always include `#!/usr/bin/env python3` at the top.
- **Entry Point:** Always use the `if __name__ == "__main__":` guard block to allow importing functions without execution.
- **Argument Parsing:** Use `argparse` for handling command-line arguments.
  ```python
  parser = argparse.ArgumentParser(description="...")
  parser.add_argument("--arg", required=True, help="...")
  args = parser.parse_args()
  ```

### Error Handling
- **Output:** Print normal output to `stdout`.
- **Errors:** Print error messages to `stderr`.
  ```python
  print(f"Error: {e}", file=sys.stderr)
  ```
- **Exit Codes:** Exit with `sys.exit(1)` (or other non-zero code) on critical errors.
- **File I/O:** Always use `try...except` blocks for file operations to handle missing directories or permission issues gracefully.

### File System Operations
- **Paths:** Use `os.path.join` for all path concatenations.
- **Encoding:** Always specify `encoding="utf-8"` when opening files.
- **Safety:** Verify paths exist (`os.path.exists`) before reading. Create directories (`os.makedirs(..., exist_ok=True)`) before writing.

## Development Workflow
1. **Explore:** Use `ls -R` or `glob` to locate relevant scripts.
2. **Analyze:** Read the existing code to mimic the style and pattern.
3. **Modify:** Edit the Python scripts ensuring no new dependencies are added.
4. **Verify:** Run the script with sample inputs to confirm the fix or feature.

## Critical Mandates for Agents
- **Preserve Knowledge:** If you encounter something tricky, use the `record-insight` skill (if available in your session) to save it.
- **No Hallucinations:** Do not invent file paths or dependencies. Verify existence first.
- **Atomic Changes:** Keep edits focused and minimal.
